# 雨中行车 · Rain Drive

第一人称的雨天驾驶场景：傍晚的城市高架，大雨，左舵车。基于 three.js（WebGL2），所有模型、贴图、声音都是代码生成的，不依赖任何外部素材。

## 运行

```bash
npm install
npm run dev      # 打开终端里给出的地址（默认 http://localhost:5183）
```

需要较新的 Chrome / Edge，并开启硬件加速。建议戴耳机。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `S` | 加速 / 刹车（自动巡航时：调节巡航车速） |
| `A` / `D` | 转向（自动巡航时：向左 / 向右变道） |
| `F` | 自动巡航 开 / 关（默认开：车道保持 + 自适应跟车） |
| `E` | 雨刮：自动 → 关闭 → 间歇 → 低速 → 高速 |
| `R` | 雨量：小雨 → 中雨 → 大雨 → 暴雨 |
| `T` | 时间：傍晚 → 夜晚 → 白天 |
| `L` | 远光灯 |
| `K` | 手动来一道闪电 |
| `PageUp` / `PageDown` | 座椅升 / 降（每次 1 cm，会记住） |
| `M` / `H` | 静音 / 帮助 |
| 鼠标 | 光标离屏幕中心越远，头转得越多 |

手动驾驶时带转向助力：松开方向键，车头会自动顺着道路方向走，按键只负责左右挪车。

## 画面是怎么来的

每帧的渲染顺序（`src/core/pipeline.js`）：

1. **后视镜**：车内镜和左右外后视镜都是真正的平面镜——把驾驶员的眼睛关于镜面做镜像得到虚拟视点，以镜片四角为视锥边界渲染外景，所以镜中的视野由「眼睛 + 镜片」的相对位置决定。三面镜子轮流更新，每帧只画一面。
2. **路面倒影**：把主相机关于路面做镜像再渲染一遍外景，然后竖向拉长模糊——湿沥青上那种长长的灯光倒影就是这么来的；积水处直接用清晰的镜像。
3. **外景**（HDR）：路面、护栏、路灯、楼群、车流、雨丝。
4. **车窗**：玻璃是真实的 3D 网格，按屏幕坐标去采样第 3 步的画面。每颗水珠是一个小透镜（里面是缩小、颠倒的外景），水膜是模糊，雨刮是时间函数——着色器解析地算出每个像素「几秒前被刮过」，只画这之后落下的水珠。
5. **内饰**：仪表台、方向盘、立柱，叠在最上面。路灯从头顶掠过时，A 柱的影子会扫过仪表台。
6. **后期**：泛光、色调映射、FXAA、胶片颗粒。

几个设计要点：

- **世界是 z 的函数**。道路中心线是两个正弦的叠加，护栏、路灯、门架、楼群都只建一份几何体，位置由顶点着色器按间距算出来，所以路是无限长的，CPU 上不用管理区块。
- **光照是解析式的**。路灯的位置也是 z 的函数，所以路面、车身、雨丝都在着色器里直接算路灯和自车大灯的光照，没有任何真实光源对象。
- **浮动原点**。每开出 2.4 km 把世界原点挪一次，开多久都不会有浮点精度抖动。
- **声音全部实时合成**（Web Audio）：雨打车顶和玻璃、胎噪、风噪、发动机、雨刮、伸缩缝的「咯噔」、雷声。

## 目录

```
src/
  main.js            入口：搭场景、主循环、按键
  config.js          道路 / 车身 / 玻璃的尺寸常量
  core/              渲染管线、天气预设、音频、输入、道路数学
  shaders/common.js  所有外景着色器共用的 GLSL（道路中心线、路灯、大灯、雾）
  world/             路面、路侧设施、天空、车流、雨丝
  car/               自车：运动模型、内饰、车窗雨滴、雨刮、后视镜、仪表
```

## 性能

默认会按帧率自动调节渲染分辨率（集显也能跑到 50~60 帧）。地址栏参数可以手动覆盖：

| 参数 | 作用 |
| --- | --- |
| `?msaa=4&ws=1` | 独显推荐：开 4x MSAA，外景用全分辨率渲染 |
| `?scale=0.75` | 固定渲染分辨率倍率（关闭自动调节） |
| `?drops=8000` | 雨丝数量（默认 5200） |
| `?t=night` / `?rain=3` | 启动时的时间（`dusk`/`night`/`day`）和雨量（0~3） |
| `?manual` | 启动即手动驾驶 |

调试用：`?autostart&warp=20`（跳过开始页并预先模拟 20 秒）、`?look=-30,5`（固定视角）、控制台里 `__rd.paused = true` 冻结画面。

## 已知的不足

- 车辆和内饰是程序化的简模，傍晚和夜里靠光影撑着，白天近看比较简单。
- 只有一条高架路这一种场景；没有匝道、隧道、收费站。
- 声音是合成的，没有用实录素材。
