# 雨中行车 · Rain Drive

第一人称的雨天驾驶场景：傍晚的城市高架，大雨，左舵车。基于 three.js（WebGL2）。自车是一个带完整内饰的车模（`public/models/car.glb`），其余的道路、楼群、车流、贴图都是代码生成的；声音除雨声和雨刮外也都是实时合成。

## 运行

```bash
npm install
npm run dev      # 打开终端里给出的地址（默认 http://localhost:5183）
```

需要较新的 Chrome / Edge，并开启硬件加速。建议戴耳机。

| `W` / `S` | 加速 / 刹车（自动巡航时：调节巡航车速） |

| `E` | 雨刮：自动 → 关闭 → 间歇 → 低速 → 高速（开局为低速） |
| `R` | 雨量：小雨 → 中雨 → 大雨 → 暴雨 |

## 画面是怎么来的

每帧的渲染顺序（`src/core/pipeline.js`）：

1. **后视镜**：车内镜和左右外后视镜都是真正的平面镜——把驾驶员的眼睛关于镜面做镜像得到虚拟视点，以镜片四角为视锥边界渲染外景，所以镜中的视野由「眼睛 + 镜片」的相对位置决定。三面镜子轮流更新，每帧只画一面。
2. **路面倒影**：把主相机关于路面做镜像再渲染一遍外景，然后竖向拉长模糊——湿沥青上那种长长的灯光倒影就是这么来的；积水处直接用清晰的镜像。
3. **外景**（HDR）：路面、护栏、路灯、楼群、车流、雨丝。
4. **车窗**：玻璃是真实的 3D 网格，按屏幕坐标去采样第 3 步的画面。每颗水珠是一个小透镜（里面是缩小、颠倒的外景），水膜是模糊，雨刮是时间函数——着色器解析地算出每个像素「几秒前被刮过」，只画这之后落下的水珠。
5. **内饰**：车模的仪表台、方向盘、立柱、座椅，叠在最上面。仪表指针和屏幕是实时画的贴图。路灯从头顶掠过时，A 柱的影子会扫过仪表台。
6. **后期**：泛光、色调映射、FXAA、胶片颗粒。

车窗上的水珠分两类（`src/car/glass.js`、`src/car/dropsim.js`）：

- **细水珠和水膜**是解析的：着色器里按格子算出来，没有状态。
- **大水珠**是模拟出来的：前挡和左右门窗上各有一组 CPU 粒子，被雨滴砸中会变大，挨着的吸成一颗，大到挂不住就开始淌（低速往下，高速被气流顶着往上或往后），一路吞掉别的水珠，身后留下一条洗干净的水痕和几颗残留小珠，被雨刮扫到就带走。每帧把它们画进一张玻璃坐标系的贴图，着色器当作又一层水珠来折射；滑过的地方另记一张「几秒前被洗过」的贴图，细水珠和水膜据此被清掉、再慢慢长回来。画质「低」档不做模拟。

几个设计要点：

- **世界是 z 的函数**。道路中心线是两个正弦的叠加，护栏、路灯、门架、楼群都只建一份几何体，位置由顶点着色器按间距算出来，所以路是无限长的，CPU 上不用管理区块。
- **光照是解析式的**。路灯的位置也是 z 的函数，所以路面、车身、雨丝都在着色器里直接算路灯和自车大灯的光照，没有任何真实光源对象。
- **浮动原点**。每开出 2.4 km 把世界原点挪一次，开多久都不会有浮点精度抖动。
- **声音实时合成**（Web Audio）：胎噪、风噪、发动机、伸缩缝的「咯噔」、雷声。实录只有四段（`public/audio/`，来源见同目录 `CREDITS.md`）：
  - 雨声（`rain.mp3`）：解码后裁掉首尾、交叉淡化成无缝循环，三路错开起点、略微变调的副本铺出立体声；雨量决定响度、低通和大雨时的第三路，车速让雨更密。
  - 雨刮（`wiper.mp3`）：按换向点切成一段段，跟着雨刮的实际摆动拼接，刮擦声按当前档位的行程时长变速。
  - 驶过声（`pass.mp3`）：同向车流里有车要从旁边车道超过自车、或被自车超过时，提前按预计并排的时刻触发，素材里最响的那一下对准两车并排；相对速度决定变速和响度，声像偏向那辆车所在的一侧。
  - 转向灯（`blinker.mp3`）：中段 8 个稳定周期做成无缝循环，打开转向灯时从头播，仪表上的箭头按循环的相位亮灭，和「嗒」「哒」两声对齐。这段素材是 CC BY-NC 3.0（署名、非商业）。

## 换车模

车模在 `src/car/model.js` 里加载，按节点名和材质名分拣成车身、方向盘、仪表屏、车窗、后视镜镜片几类。换别的模型时要改：

- `model.js` 顶部的节点名 / 材质名对照表
- `config.js` 里的 `CAR`（眼睛位置、方向盘轴线）、`GLASS`（风挡曲面的拟合参数）、`WIPERS`（雨刮尺寸）
- `cabin.js`、`exterior.js` 顶部的材质分类表（哪些从车内看不到、哪些要在外景里画）

## 目录

```
src/
  main.js            入口：搭场景、主循环、按键
  config.js          道路 / 车身 / 玻璃的尺寸常量
  core/              渲染管线、天气预设、音频、输入、道路数学
  shaders/common.js  所有外景着色器共用的 GLSL（道路中心线、路灯、大灯、雾）
  world/             路面、路侧设施、天空、车流、雨丝

public/models/       车模
```

## 性能

画质有四档预设，在开始页上选，或者行驶中按 `Q` 切换，选择会记在本机：

| 档位 | 分辨率上限 | 自动降分辨率 | 外景分辨率 | 抗锯齿 | 雨丝 | 车内阴影 | 水珠模拟 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 低 | 0.75× | 开 | 0.7× | FXAA | 2600 | 关 | 关 |
| 中（默认） | 1.25× | 开 | 0.8× | FXAA | 5200 | 768 | 1536 |
| 高 | 1.5× | 关 | 1× | 2x MSAA | 7000 | 1024 | 2048 |
| 极高 | 2× | 关 | 1× | 4x MSAA | 9000 | 2048 | 3072 |

「中」适合集显（自动调节下能跑到 50~60 帧），「高」和「极高」是给独显准备的。预设的数值在 `src/config.js` 的 `QUALITY` 里。

地址栏参数仍然可用，会覆盖预设里对应的那一项：

| 参数 | 作用 |
| --- | --- |
| `?q=high` | 启动时的画质档位（`low` / `mid` / `high` / `ultra`） |
| `?msaa=4&ws=1` | 抗锯齿采样数、外景分辨率倍率 |
| `?scale=0.75` | 固定渲染分辨率倍率（关闭自动调节） |
| `?drops=8000` | 雨丝数量 |
| `?sim=0` | 车窗水珠模拟的贴图宽度，`0` 为关闭（退回解析的水珠） |
| `?t=night` / `?rain=3` | 启动时的时间（`dusk`/`night`/`day`）和雨量（0~3） |
| `?manual` | 启动即手动驾驶 |
| `?nosample` | 雨刮、转向灯和驶过声不用实录，只留合成声（用来对比） |

调试用：`?autostart&warp=20`（跳过开始页并预先模拟 20 秒）、`?look=-30,5`（固定视角）、控制台里 `__rd.paused = true` 冻结画面。

## 已知的不足

- 车流里的其他车仍是程序化的简模。
- 自车车模的材质只有纯色，没有法线和粗糙度贴图，白天近看偏平。
- 只有一条高架路这一种场景；没有匝道、隧道、收费站。
- 除雨声、雨刮、转向灯和驶过声外的声音是合成的，没有用实录素材。
